# Moodle Downloader for macOS

Нативное приложение для скачивания доступных студенту материалов курсов с
`moodle.innopolis.university`. Приложение не запрашивает и не хранит пароль:
вход выполняется в обычном окне Moodle внутри приложения.

## Запуск для разработки

Требуется macOS 13+ и Swift 6 (достаточно Command Line Tools):

```bash
swift run MoodleDownloader
```

## Сборка `.app`

```bash
chmod +x scripts/build-app.sh
./scripts/build-app.sh
open "dist/Moodle Downloader.app"
```

Для сборки DMG с приложением, ссылкой на Applications и инструкцией установки:

```bash
./scripts/package-dmg.sh
```

Образ и файл SHA-256 сохраняются в `dist/`. Если Command Line Tools выбирает
macOS 27 SDK без SwiftUIMacros, скрипты сами переключаются на установленный
SDK macOS 26. Для ручного `swift build` укажите его явно:

```bash
SDKROOT=/Library/Developer/CommandLineTools/SDKs/MacOSX26.sdk swift build
```

## Установка готового релиза

Скачайте DMG со страницы [Releases](https://github.com/GalllaxyCode/moodle_downloader/releases),
откройте его и перетащите приложение в `Applications`. Текущая сборка локально
подписана, но не нотарифицирована Apple. При первом запуске после предупреждения
Gatekeeper откройте **Настройки системы → Конфиденциальность и безопасность** и
нажмите **Всё равно открыть**. Официальная инструкция:
[Open apps safely on your Mac](https://support.apple.com/102445).

## Использование

1. При первом запуске войдите в Moodle (включая SSO/2FA, если требуется).
2. При следующих запусках сохранённая WebKit-сессия откроет **My courses** автоматически.
3. Выберите предмет и отметьте нужные уроки или темы.
4. Внутри каждого занятия отметьте конкретные материалы: презентации, PDF,
   лабораторные или другие ресурсы. Все занятия показаны сворачиваемыми списками:
   нажмите на название занятия, чтобы раскрыть или скрыть его материалы.
5. Выберите папку назначения и формат (папка или ZIP).
6. Нажмите **Скачать выбранные материалы**.

Кнопка **Скачать видимые курсы одним ZIP** автоматически обходит все показанные
предметы, собирает доступные материалы по предметам и занятиям и создаёт единый
архив `Moodle Materials.zip`.

### Скрытие старых курсов

Нажмите значок **Скрыть курс** справа от предмета или выберите эту команду
правой кнопкой мыши. Например, так можно убрать неактуальные предметы IBC26.
Скрытые курсы не попадают в общий ZIP; выбор сохраняется после перезапуска.
Чтобы вернуть предмет, выберите его в меню **Скрытые курсы** под списком.

### Обновление скачанного курса

Выберите предмет и прежнюю папку назначения (или саму папку этого предмета),
затем нажмите **Обновить папку курса**. Приложение заново проверит весь курс,
включая новые занятия, и скачает только недостающие файлы. Уже скачанные файлы
сохраняются; в результате отдельно показаны новые файлы и те, которые уже есть.
Выбор отдельных материалов на эту кнопку не влияет.

Поддерживаются и папки, скачанные исходной версией приложения. Если материалы
сохранены только в ZIP, сначала распакуйте архив и выберите папку курса.
Обновление работает с папкой и не создаёт новый ZIP.
При первом обновлении старой папки файлы с неоднозначными именами или с сервера
без поддержки HEAD могут быть прочитаны повторно для сравнения содержимого.
После этого повторные обновления используют сохранённый список локальных файлов.

Пароль приложение не получает и не сохраняет. Moodle может периодически завершать
сессию; тогда безопасный экран входа появится снова.

Если Moodle перенаправляет на страницу авторизации, приложение автоматически
продолжает вход через доступную Innopolis SSO/IdP-кнопку или уже заполненную
WebKit форму. Сам экран появляется только тогда, когда действительно требуется
ручное действие пользователя. Стороннее расширение для этого не устанавливается.

После первого успешного входа приложение также получает официальные Moodle Mobile
токены и хранит их в macOS Keychain. При следующем запуске через
`tool_mobile_get_autologin_key` создаётся одноразовая ссылка входа. Этот механизм
повторяет открытый протокол InNoHassle Tools, но секреты не попадают в настройки,
логи или репозиторий.

Описание протокола сверено с открытым проектом
[one-zero-eight/browser-extension](https://github.com/one-zero-eight/browser-extension).

Структура результата: `<Предмет>/<номер> — <тема>/<материал.ext>`. Названия с
`Lab 1`, `Lecture 2` и похожими обозначениями нормализуются. Одинаковые имена
не перезаписываются — к следующему файлу добавляется `(2)`.

Загружаются только файлы, доступные текущей учётной записи. Приложение не
обходит ограничения Moodle и не скачивает ответы, оценки или содержимое тестов.
